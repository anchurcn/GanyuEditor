# GanyuEditor 代码重构方案

**日期**: 2024-12-20  
**目标**: 提升代码可维护性、清晰度和结构合理性

## 一、当前问题分析

### 1.1 文件位置混乱
- `StudioBone.cs` 在Scripts根目录，应该在Core文件夹
- `PhysicsDataExporter.cs` 在Editor文件夹，但它不是Editor专用脚本
- `ExportPhysicsData.cs` 全部是注释代码，应删除
- Editor文件夹中有空的Constraints和Shapes子文件夹

### 1.2 命名冲突和不一致
- `Rigidbody` 与Unity内置类名冲突
- `Constraint` 命名太通用，容易混淆
- `BoxShape` vs `CollisionShape` 命名风格不统一
- `Helper` 类名太泛化，职责不清
- `ExporterHelper` 应该遵循扩展方法命名约定

### 1.3 命名空间混乱
- `GanyuEditor` vs `GanyuEditor.Physics` 职责划分不明确
- `StudioBone.cs` 使用 `UnityEditor` 但在Runtime命名空间

### 1.4 代码质量问题
- **重复代码**: `SetupRagdollWizard` 中 `AllBodyParts()` 和 `AllBodyPartsInfo()` 重复枚举16个身体部位
- **长方法**: `BuildBodies()` 和 `BuildConstraints()` 方法超过100行
- **魔术数字**: 大量硬编码值（2.5f, 5.85f/8.1f, 0.55f等）
- **Helper类位置不当**: 嵌套在 `SetupRagdollWizard` 内部

### 5.2 提取扩展方法（StudioBoneExtensions.cs）

```csharp
using UnityEngine;
using GanyuEditor.Extensions;
using GanyuEditor.Physics;

namespace GanyuEditor.Editor.Physics.Wizards
{
    public static class StudioBoneExtensions
    {
        public static Vector3 Position(this StudioBone bone) => bone.transform.position;

        public static Matrix4x4 Transform(this StudioBone bone) => bone.transform.localToWorldMatrix;

        public static GameObject RootObject(this GameObject gameObject)
        {
            while (gameObject.transform.parent)
            {
                gameObject = gameObject.transform.parent.gameObject;
            }
            return gameObject;
        }

        public static void AddCapsuleShape(this StudioBone bone, Matrix4x4 shapeTransform, float height, float radius)
        {
            var shape = bone.gameObject.AddComponent<CapsuleCollisionShape>();
            bone.gameObject.AddComponent<PhysicsBody>();
            shape.WorldTransform = shapeTransform;
            shape.Height = height;
            shape.Radius = radius;
        }
    }
}
```

### 5.3 简化重复枚举（SetupRagdollWizard.cs 改进）

```csharp
// 旧代码 - 重复枚举16个部位
private IEnumerable<GameObject> AllBodyParts()
{
    yield return Pelvis?.gameObject;
    yield return Spine?.gameObject;
    yield return Chest?.gameObject;
    // ... 重复13次
}

private IEnumerable<(GameObject obj, string name)> AllBodyPartsInfo()
{
    yield return (Pelvis?.gameObject, nameof(Pelvis));
    yield return (Spine?.gameObject, nameof(Spine));
    // ... 重复14次
}

// 新代码 - 使用反射
private IEnumerable<StudioBone> GetAllBodyPartBones()
{
    return GetType()
        .GetFields(BindingFlags.Public | BindingFlags.Instance)
        .Where(f => f.FieldType == typeof(StudioBone))
        .Select(f => f.GetValue(this) as StudioBone);
}

private IEnumerable<(StudioBone bone, string name)> GetAllBodyPartBonesWithNames()
{
    return GetType()
        .GetFields(BindingFlags.Public | BindingFlags.Instance)
        .Where(f => f.FieldType == typeof(StudioBone))
        .Select(f => (f.GetValue(this) as StudioBone, f.Name));
}
```

### 5.4 提取Builder（RagdollBuilder.cs）

```csharp
namespace GanyuEditor.Editor.Physics.Wizards
{
    public class RagdollBuilder
    {
        private readonly SetupRagdollWizard _wizard;

        public RagdollBuilder(SetupRagdollWizard wizard)
        {
            _wizard = wizard;
        }

        public void BuildBodies()
        {
            float bodyWidth = CalculateBodyWidth();
            float headWidth = bodyWidth / RagdollConstants.BodyToHeadWidthRatio;

            BuildHead(headWidth);
            BuildUpperLimbs(headWidth);
            BuildLowerLimbs(headWidth);
            BuildTorso(bodyWidth, headWidth);
        }

        private void BuildHead(float headWidth)
        {
            float headHeight = headWidth / RagdollConstants.HeadAspectRatio;
            var headPos = _wizard.Head.Position();
            var headShapeTransform = Matrix4x4.Translate(headPos + new Vector3(0, headHeight / 2, 0))
                .Lookat(headPos, Vector3.right);
            _wizard.Head.AddCapsuleShape(headShapeTransform, headHeight, headWidth / 2);
        }

        private void BuildUpperLimbs(float headWidth)
        {
            CreateLimb(_wizard.LeftArm, _wizard.LeftElbow.Position(),
                headWidth * RagdollConstants.UpperArmWidthRatio);
            CreateLimb(_wizard.LeftElbow, _wizard.LeftHand.Position(),
                headWidth * RagdollConstants.LowerArmWidthRatio);
            CreateLimb(_wizard.RightArm, _wizard.RightElbow.Position(),
                headWidth * RagdollConstants.UpperArmWidthRatio);
            CreateLimb(_wizard.RightElbow, _wizard.RightHand.Position(),
                headWidth * RagdollConstants.LowerArmWidthRatio);
        }

        private void BuildLowerLimbs(float headWidth)
        {
            CreateLimb(_wizard.LeftHip, _wizard.LeftKnee.Position(),
                headWidth * RagdollConstants.UpperLegWidthRatio);
            CreateLimb(_wizard.LeftKnee, _wizard.LeftFoot.Position(),
                headWidth * RagdollConstants.LowerLegWidthRatio);
            CreateLimb(_wizard.RightHip, _wizard.RightKnee.Position(),
                headWidth * RagdollConstants.UpperLegWidthRatio);
            CreateLimb(_wizard.RightKnee, _wizard.RightFoot.Position(),
                headWidth * RagdollConstants.LowerLegWidthRatio);
        }

        private void BuildTorso(float bodyWidth, float headWidth)
        {
            BuildPelvis(bodyWidth);
            BuildSpine(bodyWidth, headWidth);
            BuildChest(bodyWidth, headWidth);
        }

        private float CalculateBodyWidth()
        {
            return (_wizard.LeftArm.Position() - _wizard.RightArm.Position()).magnitude;
        }

        // ... 其他辅助方法
    }
}
```

### 5.5 命名方案与重命名清单

#### 命名方案

- 对所有可挂载到 GameObject 的 `MonoBehaviour`，统一使用 `Component` 后缀
- 对应的自定义 Inspector 统一使用 `Editor` 后缀，并与运行时类名保持一致
- 纯工具类、常量类、Builder、扩展方法类不使用 `Component` 后缀
- 为提升 Unity 菜单中的可发现性，建议为组件补充 `[AddComponentMenu]`

#### 建议重命名清单

| 旧文件/类名 | 新文件/类名 | 说明 |
|---|---|---|
| `Assets/Scripts/Physics/PhysicsBody.cs` / `PhysicsBody` | `Assets/Scripts/Physics/PhysicsBodyComponent.cs` / `PhysicsBodyComponent` | 可挂载刚体组件 |
| `Assets/Editor/Physics/Inspectors/PhysicsBodyEditor.cs` | `Assets/Editor/Physics/Inspectors/PhysicsBodyComponentEditor.cs` | 对应自定义 Inspector（如需要新建） |

#### 不建议重命名的项

- `Assets/Scripts/Physics/ExportSettings.cs`：纯数据/配置类，不属于组件
- `Assets/Scripts/Extensions/*`：扩展方法、工具方法不属于组件命名范畴
- `Assets/Editor/Physics/PhysicsDataExporter.cs`、`EditorManagerEditor.cs`、`Menus/*`、`Wizards/*`：编辑器工具类，按职责命名即可

#### 实施顺序建议

1. 先重命名运行时组件类及文件
2. 再重命名对应的 Editor 类及文件
3. 最后全局搜索替换引用、`[CustomEditor]`、`[RequireComponent]`、菜单项和反射字符串
4. 完成后重新打开 Unity，让 `.csproj/.sln` 和序列化引用同步更新
